**Finding:** Test ROC-AUC 0.814. The cost-optimal threshold catches **95% of defaulters** and **cuts lending losses by 48%**. [View on Kaggle](https://www.kaggle.com/code/abrarahmedsyed313/credit-risk-prediction)
